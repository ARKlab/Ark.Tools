# Workflow engine research

This directory contains the architecture research for embedding durable,
code-first workflows in an ASP.NET Core application while reusing Azure App
Service, Azure Service Bus, Azure Storage, and Azure SQL resources.

- [Research and recommendation](research.md)

The research is a decision aid, not a compatibility promise. Package versions,
licensing, Azure pricing, and product roadmaps must be re-checked before a
procurement or production decision.
