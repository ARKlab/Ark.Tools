# AZF-09 — OpenAPI for generated Functions

**Category**: azure-functions · **Status**: DEFERRED

OpenAPI is excluded from the Azure Functions workstream by AZD-11. Do not add
Function OpenAPI dependencies, generated document endpoints, custom descriptors or
a runtime document provider.

Reopen this task only when a maintained Microsoft or community solution supports
the .NET isolated worker and the repository's OpenAPI requirements without
duplicating contract metadata. Reopening requires a new reviewed decision and a
self-contained implementation task.
